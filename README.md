# 멜찌 카드뉴스 자동 제작

월·수·금 Claude 예약 작업이 주제 선정 → 대본 → 이미지 7장 렌더링 → 이 저장소에 업로드 → 구글 시트 "카드뉴스" 탭 기록까지 합니다. 사람이 시트에서 승인하면 Make가 인스타그램에 게시합니다.

## 흐름

| 시각 | 누가 | 하는 일 | 제작_상태 |
| --- | --- | --- | --- |
| 월·수·금 20:00 | Claude | 주제·라인 선정, 대본과 표지 사진 프롬프트 작성, 시트에 행 추가 | 사진 대기 |
| 20:00~20:30 | Make 시나리오 C | 사진 프롬프트로 OpenAI 이미지 생성 → 이 저장소 `covers/<콘텐츠_ID>.png`로 저장 | 사진 완료 |
| 20:30 | Claude | 표지 포함 7장 렌더링 → `posts/<콘텐츠_ID>/` 업로드 → 이미지 URL·캡션 기록 | 검수 대기 |
| 다음 날 | 사람 | 이미지·캡션 확인 후 마케터_승인 체크 | |
| 이후 | Make | 승인된 행을 캐러셀로 게시 | |

다시 만들고 싶은 행은 제작_상태를 `다시 만들기`로 바꾸면 다음 20:30에 다시 렌더링합니다.

## Make 시나리오 C (표지 사진)

1. Google Sheets — "카드뉴스" 탭에서 제작_상태 = `사진 대기` 행 검색 (15분 간격)
2. OpenAI — 이미지 생성, 프롬프트 = 사진_프롬프트, 세로형 1024×1536
3. GitHub — 파일 만들기: 저장소 이 저장소, 경로 `covers/{{콘텐츠_ID}}.png`, 내용 = 생성된 이미지
4. Google Sheets — 그 행의 제작_상태 = `사진 완료`, 표지사진_URL = 저장된 파일 주소

## 게시용 이미지 주소

`https://raw.githubusercontent.com/<계정>/<저장소>/main/posts/<콘텐츠_ID>/01.jpg` … `07.jpg`
시트 이미지_URL 열에 쉼표로 구분해 들어갑니다. Make에서 쉼표로 나눠 캐러셀 항목으로 넣으면 됩니다.

## 폴더

| 경로 | 내용 |
| --- | --- |
| `CLAUDE.md` | 예약 작업이 따르는 실행 절차 |
